# Security Policy

## Supported Versions

| Version | Supported |
| ------- | --------- |
| 0.1.x   | Yes       |

## Reporting a Vulnerability

Please **do not** report security vulnerabilities through public GitHub issues.

Use [GitHub Private Vulnerability Reporting](https://github.com/SuzumiyaHaruhi719/llmsvet/security/advisories/new) on this repository to submit a confidential report with:
1. Minimal reproduction input (`robots.txt`, `llms.txt`, HTML payload, or CLI invocation)
2. Impact assessment
3. Suggested fix (if available)

We aim to acknowledge reports within 72 hours.
